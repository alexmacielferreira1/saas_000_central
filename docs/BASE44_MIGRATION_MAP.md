# Mapa de migração Base44

Inventário estático do export original. Nenhuma funcionalidade foi convertida.
Ocorrências são candidatas à revisão; ausência de padrão não prova ausência de dependência.
O build não comprova login, persistência, isolamento de tenant ou paridade funcional.

## Origem
ZIP: `000_central.zip`; snapshot: tag `base44-export`.
Integridade por arquivo: `docs/history/base44-manifest.json`.

## Estratégia
Preservar rotas e interface. Validar M0; em M1 preparar identidade/tenant; em M3 migrar uma fatia vertical por vez.
SDK permanece instalado. Variáveis Base44 ausentes no export não serão inventadas.
